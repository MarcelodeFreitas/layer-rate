LayerRate Architecture

LayerRate is organized around one pricing source of truth. Product surfaces collect input, call the core engine, and format or save the result.

Rule: pricing math lives only in layer-rate-core.

Visual Architecture

Terminal User Runs local commands and reads terminal output.
AI Assistant Runs the layer-rate:quote skill in Claude Code.
Browser User Uses forms, saved presets, charts, PDFs, and sharing.

Components And Stack

Core

  • TypeScript package
  • Node-compatible ESM
  • Vitest tests
  • No UI or database

CLI

  • TypeScript + Node.js
  • commander or yargs
  • Reads JSON input
  • Prints table or JSON output

Plugin

  • Claude Code skill
  • Single-file bundled CLI
  • Shop settings via userConfig
  • Rounded breakdown

Website

  • Next.js + React
  • Tailwind CSS
  • PostgreSQL
  • Prisma or Drizzle

Data Flow

1

Collect

CLI, plugin, or website receives printer, material, labor, fee, tax, and quantity inputs.

2

Build Input

The surface creates a valid LayerRateQuoteInput.

3

Calculate

calculateQuote(input) normalizes units and calculates the quote.

4

Return

Core returns raw decimals and detailed breakdowns.

5

Present

The surface rounds, formats, charts, saves, exports, or explains the result.

API Boundary

import { calculateQuote } from "layer-rate-core";

const result = calculateQuote(input);
  • Core owns: pricing math, validation, unit normalization, fees, tax, and breakdown values.
  • CLI owns: terminal commands, JSON files, terminal formatting, and local workflows.
  • Plugin owns: skill instructions, shop settings, and the bundled CLI build.
  • Website owns: users, saved presets, database, charts, rounding, currency display, PDFs, ecommerce, and sharing.
